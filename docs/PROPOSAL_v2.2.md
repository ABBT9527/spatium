## 0. 结论先行

1. **你的判断成立。** 现行 S1 机制（Tammes 覆盖–分离比 + 二维棋盘）在数学上是**二维问题**（在 2 维度量空间里放点、量最小距离），它确实更像 S3 的内容，而不是「点」的玩法。
2. **根因是两条**：(a) 混淆了**对象的维度**与**载体（棋盘）的维度**；(b) 六层共用「摆东西最大化 Φ」这一个模板时，**给 S1 挑了一个必须 ≥2 维环境才有意义的 Φ**。
3. **一条主原则（本提案的核心）**：**每层的 Φ 必须是该维度的特征不变量；棋盘必须是"该维度本身的空间"，而不是高一维的容器。**
4. **资源选法本来就对，保留**：资源 = **k 维 Hausdorff 测度** `H^k`（H⁰ 计数 / H¹ 长度 / H² 面积 / H³ 体积 / H⁴）。问题在玩法，不在资源命名。
5. **S0 的三动词目前是装饰**（α 自动爬阶梯，玩家只"填配额"）→ 需让序数运算真正**算数**。
6. **"诡异"的直接来源是资源没有出口**：实现里 `迭代 It` 无 sink、`μ` 无 sink、五行 / 公理点未实装 → 玩家在攒一堆花不掉的数字。§5 给出修法。

## 1. 诊断

### 1.1 S1「点」为什么错位（数学核对）

| 项 | 现行设计 | 「点」的真实数学 | 判定 |
|---|---|---|---|
| 载体 | 2 维方格 / 六角格位点（§4.8.2） | 点集本身**没有载体**；零维空间可嵌入一维（Cantor 集 ⊂ [0,1]） | ✗ 载体把维度抬到 2 |
| Φ | 覆盖–分离比，`δ = 最小成对距离` | 最小距离需要**度量**；在一维里它退化为"等距点"（平凡），二维才非平凡 | ✗ 这是 2 维装球（Tammes） |
| 释放的自由度 | 点的数量上限 + 最小距离约束 | 有限零维空间的**唯一不变量是基数** | ✗ 数值上变成"二维容量" |
| 叙事 | "怎么摆，才能覆盖最大的空间"（§2.1） | 零维空间**没有"空间"可覆盖** | ✗ |

**一句话**：`覆盖最大的空间` 这件事本身就是 ≥1 维的命题。**点是尘埃，尘埃不铺满任何东西。**

### 1.2 关键数学事实（决定了 S1 应该怎么做）

| 事实 | 内容 | 对玩法的含义 |
|---|---|---|
| **特征不变量** | 紧度量空间 `X` 满足 `dim X = 0` ⟺ **完全不连通**（totally disconnected，每个连通分量是单点） | 零维的"内容"是**隔离**，不是**铺展** |
| **有限情形** | 任意两个同基数的有限离散空间**同胚** | 有限点的**唯一**可优化量 = **基数** |
| **丰富情形** | **Brouwer 刻画**：非空、紧、**完美**（无孤立点）、完全不连通、可度量化 ⟹ **同胚于 Cantor 集** | 零维的"高光"是**从有限尘埃跃迁到完美尘埃** |
| **唯一的零维空间** | `2^ℕ`（二进制 Cantor 空间）= 完全二叉树边界的自相似尘埃，`dim_H = log2/log3 ≈ 0.631`，Lebesgue 测度 0 | **棋盘就该是"树/Cantor 空间本身"** |
| **与 S2 的衔接** | `[0,1]` 是 Cantor 集的**连续像**（Hahn–Mazurkiewicz；把空隙粘合） | S1→S2 涌升 = **尘埃被粘成一条线**，叙事与数学同时成立 |

> **核心结论**：要让 S1 真的是"点"，棋盘只能是**它自己就是零维的空间** —— 即 **Cantor 空间（树边界）**。在那种空间里放点、镂空、细分，才不会偷来高维结构。

### 1.3 S0 为什么空

- 现行：α 沿 ε₀ 阶梯**自动爬升**（`milestone(ladder, round, runs)`），玩家的三动词（Succ/Sup/Fix）只影响"这轮拿不拿主动档"。
- 后果：**三动词与进度无因果**，是对点击的"序数风味包装"，违反 P1（数学是机制）。P6 也不成立（收益不因"做得更好"变化）。
- 现有资产：`ordinal/cnf.ts` 序数内核（succ / sup / fix / omegaPow / cmp / milestone）**已 32/32 通过** —— **序数运算本来就能真算**，只是没被用作玩法。

### 1.4 早期 S1 尤其空（一个具体的实现问题）

`requiredPoints(lv) = max(1, lv)` ⇒ **第 1 轮只要求放 1 个点**，放哪都是最优。Tammes 只有在 N 较大时才成为谜题。
⇒ 前若干轮**根本没有玩法**，这正是"看不出玩法"的直接来源。

| 层 | 维 k | **特征不变量**（数学） | **玩家动作** | **Φ**（该维度特有，有定理上界） | 资源 `H^k` |
|---|---|---|---|---|---|
| **S0** 序数 | — | 良序 / 极限 / **不动点** / CNF | **构造**：用序数算子逼近目标序数 | 效率 = 理论最少算子数 / 实用算子数 | 迭代 It |
| **S1** 点 | **0** | **完全不连通**、基数、孤立 vs 完美、测度 0 | **镂空 / 细分**：保删 + 自相似复制 | **完美度**（非孤立点比例；满分 ⟺ 同胚于 Cantor 集） | μ = H⁰（计数） |
| **S2** 线 | 1 | **连通性**、序 / 介数、H¹、π₁（回路） | **连线**：点连成自避路径，开链 / 闭环 / 分支 | `L/总边数 × (1+χ)` | L = H¹ |

| **S4** 体 | 3 | **Kepler 密度**、晶系、表面税 | **堆积**：选晶系、粒度 | `(36πV²/S³)·δ/δ_Kepler` | V = H³ |
| **S5** 胞 | 4 | **格不变量**（λ₁、det、kissing）、投影 | **选格 / 投影** | `γ(Λ)·δ/δ_{D₄}` | H = H⁴ |

**动作链**：`构造 → 镂空 → 连线 → 铺砌 → 堆积 → 选格`
（**周期重置动词**另有一套，已在 §3.4 定案：塌缩 / 离散 / 补全 / 铺砌 / 密堆 / 晶格 —— 两者不冲突）

- **R-c**：资源 = `H^k` 这一条**已经正确**，不动。改动只在玩法侧。

## 3. S1「点」重设计

### 方案 A：镂空 —— 在 Cantor 空间里造完美尘埃 ⟢ 推荐

**空间本体**：二叉（后期 k 叉）树的**边界** `∂T ≅ 2^ℕ`，即 Cantor 空间。离散化 = 深度 `d` 的树（`d` 随 lv 增长）。
**对象**：你保留的叶子集合 `S`（= Cantor 空间的一个闭子集；每枚叶子 = 一个"点"）。

| 项 | 内容 |
|---|---|
| **零维守卫**（本方案的核心） | **任何节点的孩子不能"全保"**。否则该柱体 `⊆ S` ⇒ `S` 有内点 ⇒ 不再完全不连通 ⇒ **越层**。（离散版的"完全没有连通分量"） |
| **动作 1 · 镂空 Prune** | 删一枚叶子 → 产生一个"洞" |
| **动作 2 · 细分 Refine** | 把叶子展开一层，露出更细的洞（= 提高分辨率 = 提高点数上限） |
| **动作 3 · 自相似复制 Self-similar** | 把当前模式复制到所有存活节点 —— 这是**造 Cantor 集的手法**，也是"批量 QoL"在零维的形态（替代 S3 的矩形填充） |
| **Φ_S1 · 完美度** | `被保的、其父节点有 ≥2 个存活兄弟的叶子 / 总存活叶子`。全部孤立 ⇒ 0；每层 ≥2 分支 ⇒ →1 —— **满分时 S 紧、完美、完全不连通 ⇒ 同胚于 Cantor 集（Brouwer）** |
| **资源** | `μ = |S|`（存活叶子数）= `H⁰` = 计数测度 |
| **视觉** | 一条线段被"敲成自相似粉尘"，或一棵树叶子亮起。**与 S3 的铺砖/面积零相似** |
| **S1→S2 涌升** | `[0,1]` 是 Cantor 集的连续像 ⇒ **空隙被粘合，尘埃变成一条线** |
| **与 §5.7 衔接** | 真 Cantor 集 `dim_H = log2/log3 ≈ 0.631 ∈ (0,1)` ⇒ 正好落在 S1→S2 **分形带**内，天然衔接 |
| **实现代价** | 中：新棋盘类型（树 / 区间细分）+ 一个"完美度"泛函；判定仍是**局部谓词**、状态仍是 TypedArray，符合 §4.8 |

**为什么它同时解决"没有内容"**：树结构天然提供**多层解锁**（分叉数 b、最大深度 d、自相似复制、洞的最小尺度…）—— 每一项都是 N6 允许的"降低达到上界的代价"，而不是给倍率。

### 方案 B：计数 —— 基数即全部内容（最小改动）

| 项 | 内容 |
|---|---|
| **数学依据** | **有限零维空间的唯一不变量是基数**（同基数有限离散空间同胚）。所以 S1 诚实地做成"点数增长"层 |
| **动作** | **分裂**（1→2）；买「分裂速度」「每点产 μ 的倍率」「同时分裂数」 |
| **守卫** | 点必须**相异**（保持双射 —— 呼应 §1.3 保留的唯一约束①） |
| **Φ** | **分裂效率** = `log₂(实际点数) / 实际分裂次数`（理论最优 = 每次真分裂 ⇒ 上界 1） |
| **实现代价** | 低（不需要新棋盘） |
| **风险** | 太素，与 §4.2「玩家核心动作是摆东西」偏离；P6 难成立（收益几乎不因"摆得更好"变化） |

### 方案 C：把现行 Tammes 挪进 S3

| 项 | 内容 |
|---|---|
| **判定** | 现行 S1 的「覆盖–分离比」本质是**二维装球** ⇒ 它是 S3 的内容 |
| **修法** | S3 的 Φ 升级为**联合泛函**：`等周商 × 分离质量`（面既要"像圆"，又要"布点均匀"）；S1 改走 A 或 B |
| **代价** | 低（S3 尚未实装，正好一次定清） |

## 决议与落地（2026-10-02 用户拍板）

### Q1 · S1 = 方案 A（Cantor 空间镂空）——**已定案，暂不实现**

零维守卫 = 任何节点不得「全保」（否则造出区间 → 维度过 1 → 越层）；
Φ = 完美度（非孤立点比例）；μ = 存活叶子数。**用户明确「S1 暂时不动」，本轮不实现。**

### Q2 · S0 = 最底层构造：最简数值增长 + 换基（10 → 2）——**已实现**
用户的原始意图：S0 是底层资源，也是联动 S1–5 的核心逻辑，**绝不能有太复杂的逻辑**；
需要「可复用、构造力强」的资源增长方法；考虑用**换基**（10 → 2），base 为 2 时
**仅需 4 次后继即可到达 ε**，顺利衔接 S1。

**落地形态（已实装并通过全部关卡）**
- `n`（计数）= S0 根本资源；`base` 10 → 2；`α = hereditaryToOrdinal(n, base)`（遗传基数映射 V_b）。
- **后继** `n+1`（最简数值增长）。**换基** `base−1` **且计数归零**（S0 的周期重置），门槛 `α ≥ ω²`（⟺ `n ≥ base²`）。
- base = 2 时 **1 → ω → ω^ω → ε₀ 仅 4 阶**（n = 1/2/4/16）⇒ 抵达 ε₀ 涌升 S1。**这正是「4 次后继到 ε」**——4 个台阶。
- 设计要点：同一序数目标所需计数随基下降骤减（ω²：base 10 要 100 → base 3 要 9 → base 2 只要 4）；
  **换基必须重置计数**，否则 α 在换基下单调不减 ⇒ 门槛只生效一次、8 次换基全部白送（退化为无玩法）。
- **移除 Θ/Φ 节奏引擎**（S0 要最简）。S0 唯一的调参旋钮 = `S0_REBASE_GATE`（现 ω²）。
