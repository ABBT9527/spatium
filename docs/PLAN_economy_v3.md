## 0. 结论（一屏）

1. **取消「迭代 It」**：S0 不再产出任何跨层货币。`meta.it` / `CycleResult.itYield` / `HEX_COST` 全线退休（迁移清单见 §5）。
2. **货币分两阶**：
   - **0阶货币** = 每层自己的主资源：**S0 序数 α(↔ n) / S1 ε / S2 长度 L / S3 面积 A / S4 体积 V**（S5 超体 H）。
   - **1阶货币「序 Order」**（用户 2026-10-02 命名）= **离散阶段每次从 S4 重回 S0** 才 +1，
     **0阶重置中保留**，用来买 1阶升级（**独立界面**，首次完成 S4 后解锁、可随时切换）。
3. **两个阶段**（取代旧「阶段 I / 阶段 II」的叫法）：

| 阶段 | 形态 | 0阶货币 |
|---|---|---|
| **离散阶段** | 一次只有一个层（S0 → S1 → … → S4） | **不保留**：每层「自产自销」，离开即清零 |
| **整合阶段** | S0 ~ S5 同时在线 | **作为一条链贯穿 S0~4**：`序数 → ε → L → A → V → H`，链头 = S0 的后继 |

4. **S0 终局（定案）**：换基到 base 2 → **后继 ×4**（n = 4 = `2↑↑2`，α = **ε₀**）→ **切换阶段到 S1.点**。
5. **ε 归位**：ε 不再是「跨层货币」，而是 **S1 的 0阶主资源**（在 S1 用点操作获取）。

> **这条编号链就是旧文档 §4.7「生产链 = 边界链」的那条链**，只是把链头的 `迭代 It` 换成了 `序数`：`序数 → ε → L → A → V → H`。整合阶段 = 整条链同时通电；离散阶段 = 每层单独通电、下游不存在。

## 1. 货币表

| 阶 | 货币 | 归属 | 产出方式 | 保留 | 用途 |
|---|---|---|---|---|---|
| **0** | **序数 α**（与自然数双射；n 是其坐标） | S0 | 后继 / 极限 / 升级 | 离散：层内。整合：链上 | 自身增长；在整合阶段作为链头喂给 S1 |
| **0** | **ε** | S1 | **点操作**（待设计，见 §3） | 同上 | S1 层内消耗；整合阶段喂给 S2 |
| **0** | **L / A / V / H** | S2 / S3 / S4 / S5 | 各自层的构形引擎（Φ 泛函） | 同上 | 该层建筑与升级 |
| **1** | **序 Order**（`meta.order1`） | 全局 | **离散阶段每次 S4 → S0 折返 +1** | **跨 0阶重置保留** | **买 1阶升级**（独立界面；S4 未实装 ⇒ 现恒 0、界面显示「未解锁」） |

**「0阶重置」** = 一层的周期重置 + 离开该层时的清空。**1阶货币是唯一跨过它的东西。**
**升级归属**（用户 Q2 定案）：**0阶货币买 0阶升级**（S0~4 各有自己的升级表，各用本层货币），
**1阶货币买 1阶升级**（独立界面）。⇒ S0 的升级用**计数 n** 购买（花 n 会降低 α，是设计张力）。

## 2. S0 流程规范（已落地的实现口径）

```
主资源   ：序数 α（与自然数双射）；内部坐标 = 计数 n
增长方式 ：后继 n += succGain（并给极限槽充能） · 极限（耗整槽，推一级台阶） · 升级
周期重置 ：换基 base − 1，台阶 m 与计数 n 归零，门槛逐次抬高
门槛     ：台阶 m ≥ 2 + 已换基次数  ⇒ 所需极限次数 = 2,3,…,9（严格递增）
终局     ：base = 2  →  后继 ×4（n = 4 = 2↑↑2）  →  α = ε₀  →  切换到 S1.点
```

- **ε₀ 阈值 = `base↑↑base`**（见 `PROPOSAL_S0_v3.md §6`）：base 2 时 ε₀ 落在 **n = 4**。所以 base 2 段**不需要按「极限」**——4 次后继直接到位（用户原话「此处要进行 4 次后继，而非四次极限跃迁」）。
- ⚠️ **门槛的载体从「计数 n」修订为「台阶 m」（实现期发现，已落地）**：后继也产计数 n，
  而 `n ≥ base^(2+k)` 这个等价量在 base 10 只要 100 次后继就能达到 ⇒ 极限与 2..9 表双双失效。
  改记**动作计数** `m`（每完成一次极限 +limitJump 级）后：
  - 门槛 = `m ≥ 2 + k`，**每基所需极限次数严格 2..9，合计 44**（headless 冒烟已断言）；
  - `n ≥ base^(2+k)` 作为**等价展示量**保留（极限把 n 抬到 base^m，两者同向）；
  - base 2 段仍只需 4 次后继（门槛不参与该段）。
- **极限的粒度**：`n ← max(n, base^m)`，`m` 为本基已完成的极限级数。所需 n 全部 ≤ `78125`，
  **不需要 Decimal 就能算**（若改成「跃迁到下一 ω-深度点」，base ≥ 9 时门槛会落到 `9^(9^9)` 级别，内核实数域撑不住）。

> ⚠️ 用户新表述「后继 4 次**并极限**后到达 ε₀」有两种读法，本规划取 **(R2)**：
> - **(R2)【采用】**「极限」= **取幂塔的极限**（数学动作，不是按钮）⇒ n = 4 时值已达 ε₀，S0 结束。
> - (R1)「极限」= 还要**按一次「极限」按钮** ⇒ 那需要把「极限」改成**深度跃迁**，代价是所有换基门槛变成 1 次极限即可满足（D2「逐次抬高」失效）。
> 若你要的是 (R1)，回一句即可，我改 §2 与 §3.2。

## 3. S1 骨架（ε 的获取 · 用户标注「仍待设计」）

**已定**：
- S1 主资源 = **ε**（不是旧的「测度 μ」）。
- 获取方式 = **对点的操作**。
- 几何载体 = **Cantor 空间 2^ℕ 镂空**（`PROPOSAL_v2.2` Q1=A 已定案，但「暂不实现」）。

**待设计（我给出的候选骨架，供你选/改）**：

| 方案 | 点操作是什么 | ε 的来源 | 与「0维 = 镂空」是否自洽 |
|---|---|---|---|
| **(甲) 钻孔 Puncture** | 在 Cantor 空间里**删掉一个柱集**（前缀）| 每钻一个孔，ε 增速 ×(1+δ) | ✓ 删点 = 降维直觉 |
| **(乙) 逼近 Approach** | 放一串**直径 → 0 的点列**去逼一个目标点 | 逼近进度 = ε 产出率 | ✓ 0维 = 只用可数点逼近 |
| **(丙) 覆盖 Cover** | 用最少的开区间盖住已有点集（紧致性） | 覆盖质量 = ε/秒 | ✓ 与旧 Φ（覆盖–分离比）连续 |

**链式换算（整合阶段）**：用户定「**4 次 S0 后继 = 1 ε**」。
- 这个 4 与 base 2 的 `ε₀ = 2↑↑2 = 4` **同源**——即 **S0→S1 的链式换算率 = `base↑↑base`（在 base 2）**。
- 建议实现成一个**显式的链常数** `CHAIN_S0_TO_S1 = 4`，而不是散落的 magic number。
